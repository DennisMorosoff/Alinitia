# Добавление персонажей Pathbuilder 2e

1. В Pathbuilder 2e открой персонажа и выбери **Export JSON**.
2. Открой `characters.json`.
3. Вставь полученный объект в корневой массив через запятую:

```json
[
  { "success": true, "build": { "...": "первый полный экспорт" } },
  { "success": true, "build": { "...": "новый полный экспорт" } }
]
```

Другие файлы менять не требуется. После перезагрузки герой автоматически появится в стартовом выборе и в debug-списке.

Требования:

- сохраняй объект экспорта целиком, включая оболочку `success` и `build`;
- у каждого персонажа должно быть уникальное `build.name`;
- `characters.json` должен оставаться валидным JSON-массивом: между объектами нужна запятая;
- карманные деньги `build.money` не заменяют общую казну игры;
- инвентарь извлекается из `equipment`, `weapons`, `armor`, `pets` и `familiars`.

## Перевод инвентаря

Экспорт Pathbuilder оставляй неизменным. Русские названия добавляй в `inventory-translations.json`:

```json
{
  "English item name": "Русское название"
}
```

Если перевода ещё нет, игра покажет исходное название предмета.
